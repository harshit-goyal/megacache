# MegaCache SDKs

Version 1.0.0 SDK source, package metadata, examples, and conformance tests:

- [`python`](python/README.md) — install the repository root package
- [`node`](node/README.md) — package `@megacache/client`
- [`go`](go/README.md) — module `github.com/harshit-goyal/megacache/sdk/go`
- [`java`](java/README.md) — coordinate `io.megacache:megacache-client`

Run `make conformance`; unavailable toolchains are reported as skipped rather
than claimed as validated.
